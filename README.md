# ระบบรายงานประจำวัน (Daily Report)

เว็บสำหรับทำรายงานผลการปฏิบัติงานประจำวัน โดยมีโครงสร้างเหมือนไฟล์ Word ต้นแบบ (หัวกระดาษ/โลโก้ ท้ายกระดาษ ขอบกระดาษ ฟอนต์ TH SarabunPSK ระยะห่าง ย่อหน้า ตารางรูป)

## ความสามารถ

| หน้า | ทำอะไรได้ |
|---|---|
| **ตั้งค่าเทมเพลต** | 3 แบบ: วันธรรมดา / วันหยุด / รายงานพิเศษ — แก้ข้อความ เพิ่ม/ลบ/ลากย้ายหัวข้อ ปรับรูปแบบย่อหน้า จำนวนช่องรูป ตัวแบ่งหน้า พร้อมตัวอย่างหน้าเอกสารจริง |
| **สร้างรายงาน** | เลือกวันที่ (ระบบเลือกวันธรรมดา/วันหยุดให้อัตโนมัติ) → ใส่รูปทุกหัวข้อ + รายงานเหตุการณ์ประจำวัน (ข้อความ + รูป เพิ่มได้หลายเหตุการณ์ ทั้งผลัดกลางวันและกลางคืน) → บันทึกอัตโนมัติ |
| **จัดหน้า** | ในหน้าตัวอย่าง: ย้ายหน้า ↑↓, ลบ/ซ่อนหน้า, แทรกหน้ารูปภาพหรือหน้าว่าง |
| **ส่งออก** | Word (.docx), PDF, พิมพ์ |
| **รายงานทั้งหมด** | ค้นหา เปิดแก้ไข ทำสำเนา ลบ เลือกหลายรายงาน (เช่น ทั้งเดือน) แล้วรวมเป็น Word/PDF ไฟล์เดียว |
| **รวม/จัดหน้า PDF** | รวมไฟล์ PDF/รูปภาพ/รายงาน, ลากเรียงหน้า, หมุน, ทำซ้ำ, ลบหน้า, แทรกหน้าว่าง, แยกหน้าที่เลือก |
| **ตั้งค่า** | ซิงก์ Google Drive (ใช้หลายเครื่อง), วันหยุดนักขัตฤกษ์, สำรอง/กู้คืนข้อมูล (.zip) |

## การเก็บข้อมูล

- ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง (IndexedDB) ใช้งานได้ทันทีแม้ออฟไลน์
- ถ้าตั้งค่า **ซิงก์ Google Drive** (หน้า "ตั้งค่า") ข้อมูลทั้งหมดจะเก็บใน Google Drive ของคุณเอง ใช้ได้ทุกเครื่อง (คอม/มือถือ) ฟรีและไม่มีวันหมดอายุ — โค้ดฝั่ง Drive อยู่ที่ [`apps-script/Code.gs`](apps-script/Code.gs) มีวิธีติดตั้งในไฟล์และในหน้าตั้งค่า
- เครื่องใหม่ตั้งค่าได้ด้วยการสแกน QR / เปิดลิงก์จากหน้าตั้งค่าของเครื่องเดิม

## เปิดใช้งานเว็บ (GitHub Pages)

1. รวม (merge) โค้ดเข้า branch `main`
2. ที่ GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไม่ต้องมีเซิร์ฟเวอร์และไม่ต้อง build — ไลบรารีและฟอนต์ทั้งหมดอยู่ใน repo แล้ว (`js/lib`, `fonts`) จึงไม่ขึ้นกับ CDN ภายนอก

ทดลองในเครื่อง: `python3 -m http.server` แล้วเปิด http://localhost:8000

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
css/app.css           หน้าตา + ขนาดหน้า A4
js/skeletons.js       โครงไฟล์ Word จากไฟล์ต้นแบบ (หัว/ท้ายกระดาษ สไตล์ ขอบกระดาษ) — base64
js/defaults-data.js   โครงสร้างย่อหน้า/ตารางที่ถอดจากไฟล์ต้นแบบ
js/defaults.js        เทมเพลตเริ่มต้น 3 แบบ
js/layout.js          เอนจินจัดหน้า (ใช้ทั้งหน้าตัวอย่าง, PDF, พิมพ์)
js/docx.js            สร้างไฟล์ Word
js/export.js          ส่งออก Word / PDF / พิมพ์
js/sync.js            ซิงก์ Google Drive
js/page-*.js          หน้าต่าง ๆ ของเว็บ
apps-script/Code.gs   โค้ดสำหรับ Google Apps Script (ตัวเก็บข้อมูลบน Drive)
tools/build_from_samples.py  สคริปต์สร้าง skeletons.js / defaults-data.js จากไฟล์ .docx ต้นแบบ
fonts/                TH Sarabun New (ฟอนต์แห่งชาติ) + Sarabun สำหรับหน้าจอ
```

## หมายเหตุ

- ไฟล์ Word ระบุฟอนต์ **TH SarabunPSK** เหมือนต้นแบบ — เครื่องที่เปิดไฟล์ควรติดตั้งฟอนต์นี้ (หน้าเว็บ/PDF ใช้ TH Sarabun New ที่หน้าตาเหมือนกัน)
- PDF สร้างจากภาพหน้าเอกสารความละเอียดสูง (ภาษาไทยแสดงถูกต้องทุกตัวอักษร) ถ้าต้องการข้อความแบบเลือก/ค้นหาได้ ให้ใช้ปุ่ม "พิมพ์" → บันทึกเป็น PDF
- ถ้าต้องการเปลี่ยนไฟล์ต้นแบบ (เช่น โลโก้/ที่อยู่ท้ายกระดาษใหม่): `python3 tools/build_from_samples.py รายงานประจำวัน.docx รายงานพิเศษ.docx`
